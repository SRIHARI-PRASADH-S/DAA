# CO1_AT1 – ShopSphere Scalability Audit

**Course:** CSA06 – Design and Analysis of Algorithms  
**Assessment:** CO1 Assessment Tool 1  
**Topic:** Scalability Audit of an E-Commerce Platform

## Repository contents
- `Question_1/Source_Code/main.py` – runnable Python program with operation-count and timing estimates.
- `Question_1/Report/Report.pdf` – solution, derivations, analysis, recommendations, and execution evidence.
- `Question_1/Report/source_code.png` – source-code screenshot.
- `Question_1/Report/program_output.png` – executed output screenshot.
- `Question_1/Supporting_Files/` – reserved for any additional files.

## Run the program
Python 3 is required. No external packages are needed.

```bash
cd Question_1/Source_Code
python main.py
```

## Important interpretation
The server capacity in the question is 10^8 basic operations/second. Timing figures for recurrence-based modules are estimates based on the stated mathematical models; actual runtimes depend on constants, data structures, I/O, and implementation.
